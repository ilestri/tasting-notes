# 페이지 스타일 스코프 정리

## 규칙 요약

- **페이지 래퍼**: `.page-<name>`
  - 페이지 전용 스타일은 반드시 래퍼 아래에서만 선언합니다.
- **컴포넌트 클래스**: `.c-<name>`
  - 재사용 가능한 UI 블록/컴포넌트 스타일.
- **유틸리티 클래스**: `.u-<name>`
  - 단일 목적(색상/상태/버튼 변형 등).

## 페이지 래퍼 목록

- `page-notes`
  - 메인 목록 페이지
  - 관련 범위: 필터 그리드, 카드 그리드, 페이지네이션
- `page-detail`
  - 노트 상세 페이지
  - 관련 범위: 제품 정보, 평점/메모, 상세 헤더
- `page-stats`
  - 통계 페이지
  - 관련 범위: 요약 카드, 패널/막대 시각화

## 관리 팁

- 새로운 페이지를 만들 때는 최상단에 `page-<name>` 래퍼를 추가합니다.
- 특정 페이지 전용 스타일은 반드시 `.page-<name> .c-...` 형태로 제한합니다.
- 전역 컴포넌트 스타일은 `c-` 접두어를 유지합니다.
